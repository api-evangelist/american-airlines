# American Airlines

American Airlines Group Inc. is the world's largest airline by fleet size and revenue. Headquartered in Fort Worth, Texas, American Airlines operates an extensive domestic and international network serving nearly 350 destinations in more than 50 countries, and is a founding member of the Oneworld alliance.
